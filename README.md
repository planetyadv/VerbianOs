# 🚀 Verbian OS — Ultra-Lightweight Android TV Launcher

**Verbian OS** — это сверхбыстрый, бескомпромиссно легкий лаунчер для Android TV, созданный специально для старых и слабых телевизоров (включая KIVI TV на 1 ГБ ОЗУ, работающих по умолчанию в 15 FPS из-за тяжелых стандартных оболочек и слежки).

Написан на чистой **Java** без лишних фреймворков, с полным аппаратным ускорением графики и нулевой фоновой нагрузкой.

---

## ✨ Особенности Verbian OS

- ⚡ **Стабильные 60 FPS даже на старых процессорах:** Полное аппаратное ускорение (`hardwareAccelerated="true"`), отсутствие фоновых служб телеметрии и аналитики.
- 🎯 **Дизайн в точности как на вашем макете:** 
  - Фирменная глубокая фиолетовая тема (`#1a003c`).
  - Плавное фиолетовое неоновое выделение карточек (`#a259ff`) с аппаратной плавной анимацией масштабирования (scale 1.06x) при навигации пультом.
  - Боковая панель быстрого доступа (YouTube, Lite Web, Apps, Settings).
  - Секция **Recently Used** и кнопка в форме капсулы **"See all apps on this TV"**.
- 🌐 **Браузерные веб-ярлыки (Web Shortcuts) с околонулевым жором ОЗУ:**
  - Встроенный легковесный `LiteWebActivity` (открывает YouTube Lite, Twitch, Кино, стримы без пожирания 500+ МБ ОЗУ, как это делает стандартный Chrome).
  - Возможность прямо с пульта добавить любой веб-ярлык кнопкой **"+ Add Web Shortcut"**.
- 🎮 **100% поддержка пульта ДУ (D-Pad):**
  - Стрелки (Вверх/Вниз/Влево/Вправо), кнопки OK/Enter, кнопка Назад (Back) не закрывает лаунчер в черный экран, а плавно возвращает фокус.
- 📦 **Показ всех установленных приложений:**
  - Поддержка как ТВ-приложений (Leanback), так и сторонних/sideloaded APK.

## 🛠️ Сборка через GitHub Actions (Без сборки на ПК)

Проект полностью настроен для автоматической сборки в облаке GitHub Actions.

### Инструкция по сборке:

1. Создайте новый репозиторий на GitHub (например, `VerbianLauncher`).
2. Запушьте код в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Verbian OS TV Launcher"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/VerbianLauncher.git
   git push -u origin main
   ```
3. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
4. Вы увидите запущенный воркфлоу **"Build Verbian OS APK"**.
5. Через 1-2 минуты воркфлоу завершится, и в блоке **Artifacts** появится готовый файл:
   - `VerbianOS-Debug-APK` (готовый к установке APK-файл!).

## 📺 Установка на телевизор (KIVI / Любой Android TV)

### Способ 1: Через USB-флешку
1. Скачайте `app-debug.apk` из артефактов GitHub Actions на флешку.
2. Вставьте флешку в телевизор.
3. Откройте любой файловый менеджер на ТВ (или установите X-plore / AnExplorer из Google Play) и установите APK.
4. Нажмите кнопку **Home** на пульте — система спросит, какой лаунчер использовать по умолчанию. Выберите **Verbian OS** -> *Всегда*.

---

### Способ 2: Через ADB (Рекомендуется для максимальной производительности)

На телевизорах KIVI стоковый лаунчер и системные сервисы KIVI Media жестко нагружают процессор и ОЗУ фоновыми процессами и трекингом. 

Чтобы телевизор буквально «летал»:

1. Включите **Отладку по USB/сети** в настройках разработчика на телевизоре.
2. Установите Verbian OS:
   ```bash
   adb connect IP_ВАШЕГО_ТВ:5555
   adb install -r app-debug.apk
   ```
3. Отключите тяжелый дефолтный лаунчер KIVI / Android TV Home, чтобы освободить до 400 МБ оперативной памяти:
   ```bash
   # Заморозка стандартного лаунчера (название зависит от модели, обычно одно из следующих):
   adb shell pm disable-user --user 0 com.google.android.tvlauncher
   adb shell pm disable-user --user 0 com.kivi.tv.launcher
   adb shell pm disable-user --user 0 com.google.android.tungsten.setupwraith
   ```
   *(Если когда-то понадобится вернуть назад: `adb shell pm enable <package>`)*

После этого телевизор будет моментально загружаться сразу в **Verbian OS** с плавной работой без просадок до 15 кадров!
